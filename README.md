## 🚀 Sobre o Projeto
O **Conecta+** tem como objetivo promover a inclusão social e o acesso a conexões seguras e acessíveis para pessoas com deficiência. O sistema conta com recursos de acessibilidade visual (Validação WCAG), formulários interativos estruturados com validação via JavaScript e persistência de dados local (`localStorage`).

---

## 📂 Estrutura de Diretórios
* `.cursor/rules/` — Regras de desenvolvimento e padrões de código.
* `CSS/` — Estilização focada em acessibilidade (`estilo.css`).
* `Docs/` — Documentação acadêmica (`diario-bordo.md`, `plano-contexto.md`).
* `HTML/` — Estruturação semântica das páginas (`index.html`).
* `JS/` — Scripts de interatividade e lógica de formulários (`interatividade.js`).
